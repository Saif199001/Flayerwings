# Flayer Wings 2.0

Modern rebuild of Flayer Wings as an AI, Software & SaaS technology company.

## Locked stack
- Frontend: React
- Backend: Django 5.x + REST API
- Production database: PostgreSQL
- Google AI Studio: development accelerator only

## Strategic model
- SaaS: primary long-term focus
- Social Media Management: lean short-term cashflow/service arm
- Free Tools: audience acquisition, SEO and lead generation

## Development
The `v2-rebuild` branch is the active rebuild branch. The legacy website remains preserved on `master` as reference material.
